Camera Browser Navigation

Control page scrolling with hand gestures

How to use:

  1. Click "Enable Camera" to start
  2. Make a pinch gesture (thumb + index finger together)
  3. Move your hand up/down while pinching to scroll
  4. Release pinch to stop scrolling

Toggle: Ctrl + Shift + G
